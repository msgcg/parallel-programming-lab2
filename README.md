## Описание работы
Многопоточное приложение на Java, демонстрирующее создание вычислительных потоков через наследование от класса `Thread` (`ComputeRects`, `ComputeOvals`) и реализацию интерфейса `Runnable` (`ComputeLines`), синхронизацию разделяемых графических ресурсов (`synchronized`), управление группами потоков (`ThreadGroup`), приоритетами потоков (`setPriority`), а также сравнительный бенчмарк параллельных вычислений.

## Состав файлов
- `MultiThreadApp.java` — исходный код графического интерфейса (Swing) и встроенного вычислительного бенчмарка.
- `test_jstack.py` — утилита анализа состояний потоков в JVM через утилиту `jstack`.
- `.vscode/` — конфигурационные файлы для разработки в Visual Studio Code (`tasks.json`, `launch.json`, `settings.json`).

## Сборка и запуск

### 1. Компиляция
```bash
javac MultiThreadApp.java
```

### 2. Запуск графического интерфейса
```bash
java MultiThreadApp
```

### 3. Запуск консольного бенчмарка параллельных вычислений
```bash
java MultiThreadApp --benchmark
```

### 4. Инспекция состояний потоков в JVM
```bash
python test_jstack.py
```
