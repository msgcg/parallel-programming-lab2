# Лабораторная работа №2: Потоки и процессы в языке JAVA

**Дисциплина**: Параллельное программирование (Распределенное программирование)  
**Авторы**: Эрденко М. Д., Разгуляев Е. О. (группа ПО-32б, ЮЗГУ)  
**Преподаватель**: Ефремова И. Н.

## Описание
Многопоточное приложение на Java 25, демонстрирующее создание потоков через наследование от `Thread` и реализацию интерфейса `Runnable`, синхронизацию общих ресурсов (`synchronized`), управление приоритетами потоков и бенчмарк параллельных вычислений.

## Состав репозитория
- `MultiThreadApp.java` — основное приложение (Swing GUI + CLI бенчмарк).
- `test_jstack.py` — скрипт инспекции состояний потоков в работающей JVM утилитой `jstack`.

## Запуск
```bash
# Компиляция
javac MultiThreadApp.java

# Запуск графического интерфейса
java MultiThreadApp

# Запуск вычислительного бенчмарка в консоли
java MultiThreadApp --benchmark
```
